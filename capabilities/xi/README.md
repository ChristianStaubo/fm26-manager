# xi: who plays (playbook §7)
**Interface:** `fm xi [--fresh]` → the suggested XI for our tactic (`config/tactic.json`, shape only),
with alternatives per slot.
**How:** ability (CA) anchors the pick; this season's output moves it; natural position and new
signings count. On holiday, "Use team selection where possible" makes the XI that is set in the
game play: setting it in the game is not automated yet.
**Never:** changes the tactic.
